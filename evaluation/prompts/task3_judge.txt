You are one judge in a cross-model evaluation panel for SarcBench Task 3:
controlled sarcasm generation.

You will evaluate a candidate sarcastic comment written for a conversation
context, intended meaning, target, and preferred mechanisms. Judge only the
candidate's quality for this sample. Do not infer or reward the identity of the
candidate model. Apply the same rubric to every candidate, regardless of writing
style, language, or length.

----------------------------------------
Bias Control Rules
----------------------------------------

- Do not give a higher score merely because the candidate is longer, more
  elaborate, more emotional, or uses more rhetorical devices.
- A short sarcastic comment can be excellent if it preserves meaning, fits the
  thread, and realizes the requested mechanisms.
- A fluent or funny comment should fail if it changes the intended meaning,
  mocks the wrong target, ignores the context, or is not actually sarcastic.
- The reference comment is a quality anchor, not a required wording. Accept
  different wording when it preserves the same meaning and pragmatic function.
- Do not reward candidates that explicitly explain the intended meaning instead
  of expressing it through sarcasm.
- Do not require all preferred mechanisms if combining them would be unnatural;
  judge whether the candidate reasonably attempts the requested mechanisms while
  remaining plausible.

----------------------------------------
Criteria
----------------------------------------

Evaluate each criterion independently:

1. meaning_preserved
   True if the candidate conveys the given intended meaning. False if it changes
   the stance, weakens the criticism into something unrelated, or states a
   contradictory implication.

2. sarcastic_tone
   True if the candidate actually reads as sarcasm in context. False if it is
   purely literal, purely explanatory, or only a neutral paraphrase.

3. context_fit
   True if the comment could naturally appear after the given thread. False if
   it ignores the thread, introduces unsupported facts, or sounds detached from
   the conversation.

4. target_consistency
   True if the comment mocks or criticizes the intended target or a directly
   compatible target from the context. False if it attacks the wrong person,
   object, platform feature, or claim.

5. mechanism_alignment
   True if the candidate reasonably realizes the preferred mechanisms:
   - polarity_reversal: surface praise/approval implies criticism;
   - exaggeration: deliberate overstatement signals ridicule or criticism;
   - understatement: deliberate downplaying carries the stronger implied stance;
   - rhetorical_question: a non-genuine question implies the judgment;
   - contrast_with_context: sarcasm depends on mismatch with context;
   - sarcasm_marker: emoji, punctuation, particles, or platform cues help mark
     the nonliteral stance;
   - other: a plausible sarcastic realization not covered above.
   False if the candidate ignores the requested mechanism set when it could have
   used it naturally.

6. natural_style
   True if the wording sounds like a plausible human online comment in the
   thread's language and register. False if it sounds like an instruction,
   explanation, translation artifact, or generic template.

7. overall_pass
   True only if the candidate is broadly usable as a benchmark-quality sarcastic
   comment for this sample. Usually this requires meaning preservation,
   sarcastic tone, context fit, target consistency, and natural style. Minor
   mechanism imperfections may still pass if the comment works well overall.

Intended meaning: The speaker criticizes the transit service for being
unreliable while pretending to praise it.
Target: the transit service

Reference sarcastic comment: "Fantastic, nothing says world-class transit like
turning every commute into a surprise endurance event."
Candidate sarcastic comment: "Brilliant service, really setting the gold
standard for making a ten-minute trip feel legendary."
